راه‌اندازی رایگان Ollama

  1. Ollama را از ollama.com/download نصب و اجرا کن.
  2. در ترمینال، یک مدل دریافت کن (برای فارسی، Qwen3 گزینهٔ پیشنهادی است):
ollama pull qwen3:8b

اگر سیستم حافظهٔ محدودی دارد، مدل کوچک‌تر را امتحان کن:

ollama pull qwen3:4b

برای اجازهٔ اتصال مرورگر سایت به Ollama، برنامهٔ Ollama را ببند و سرور را با مبدأ مجاز اجرا کن:

Windows PowerShell

$env:OLLAMA_ORIGINS="https://ehsan-movahed.github.io"
ollama serve

macOS / Linux

OLLAMA_ORIGINS="https://ehsan-movahed.github.io" ollama serve

سپس این صفحه را تازه‌سازی کن و از فهرست بالا مدل نصب‌شده را انتخاب کن. دانلود مدل فقط یک‌بار انجام می‌شود. مدل‌ها و گفت‌وگوها روی دستگاه خودت می‌مانند.
